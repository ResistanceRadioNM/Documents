# Resistance Radio Creative Suite Bot

## Overview
The **Resistance Radio Creative Suite Bot** is a multi-platform social media content generator designed for progressive organizers, digital creators, and activists. It delivers emotionally intelligent, politically conscious, and meme-savvy content across:

1. **Pinterest**  
2. **Instagram**  
3. **Flashes**  
4. **Lemon8**  
5. **TikTok Share**  
6. **Meme Copy Output**

This bot is optimized for resistance-oriented storytelling, protest visuals, mutual aid messaging, and platform-native formatting.

---

## Key Features

- Emoji Placement Rule: Emojis are integrated naturally within the text—never clustered at the end of captions or descriptions. This enhances readability, tone consistency, and emotional pacing.
- 🔁 **Multi-Platform Content Generation**
- 🎨 **Style Preset System** (50 curated creative directions)
- 🧠 **Context-Aware Messaging** (based on images and prompts)
- 💬 **Alt Text and Accessibility Support**
- 🗳 **User-Directed Output Options**
- 🌐 **Spanish-Language Toggle**

## Workflow

### Image Upload Prompt

Would you like to use a style preset for this post?
Yes


No


### If "No"
Bot generates full Resistance Radio output suite in default order.

### If "Yes"
User is presented with 50 curated style presets.  
The bot also recommends 3 presets based on context, mood, or visual content.

---

## Post-Output A/B Test Prompt
After generating the full output suite, the bot will ask:

Would you like to run an A/B test for this post using the same preset (1) or something different? (2)
### If "1" (Same Preset)
The bot regenerates outputs with slight variations.

### If "2" (Different Preset)
The bot suggests 3 alternative presets, or shows the full list of 50 if requested. Then generates the A/B outputs using the new preset.

- Poll + Engagement Prompt

- Tag Suggestions  
- Hashtags  
- Location Tag  
- Alt Text  

### Flashes
- Title

- CTA + Format Tip

- Alt Text

- Visual & Layout Tips
